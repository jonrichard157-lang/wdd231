Resource & Content Attributions

This project was created for educational purposes as part of WDD 231 Web Frontend Development I at BYU-Pathway Worldwide. The following resources, fonts, tools, and content citations were utilized in the creation of the TechSparks Brasil web application:

1. Typography & Web Fonts

  • Roboto Font Family: Designed by Christian Robertson, provided via Google Fonts under the Apache License 2.0.

2. Graphical & Media Assets

  • Logo & Icons: Original vector SVG logo and favicon crafted using SVG geometric primitives and tech circuit paths.
  • Hero Banner Graphics: High-resolution abstract digital circuit network banner generated and optimized in WebP format (hero-tech.webp).
  • Startup Cards Visuals: Thematic sector gradient banners and iconography for the 18 featured Brazilian startups generated and optimized in lightweight WebP format.

3. Startup Ecosystem Information & Data

  • Company overviews, founder details, valuations, and venture funding statistics synthesized from public technology news sources, press releases, and industry databases, including:
    • Associação Brasileira de Startups (Abstartups)
    • Startups.com.br
    • Distrito Dataminer Innovation Reports
    • Crunchbase Latin America Profiles

4. Academic & Technical Standards

  • Course Curriculum: BYU-Idaho CSE WDD 231 Course Materials.
  • Web Development Standards: MDN Web Docs for semantic HTML5 elements, CSS Grid, LocalStorage API, and Fetch API.
  • Modern CSS Reset: Inspired by modern-normalize (MIT License).
